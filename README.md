# SpaceGalleryDex 🌌 — Télescopes NASA

Galerie NASA Images API avec raccourcis intégrés pour :
James Webb, Hubble, Chandra, Spitzer, Kepler, TESS, Fermi, WISE, Swift, NuSTAR, GALEX, SDO, SOHO et Nancy Grace Roman.

Un clic sur un télescope lance directement la recherche d'images correspondante dans la NASA Image and Video Library.

- 20 images par page
- filtre par année
- recherche libre
- aperçu détaillé
- aucune clé API
- compatible GitHub Pages
